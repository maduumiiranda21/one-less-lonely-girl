# 💜 One Less Lonely Girl - Music Experience

Uma experiência musical interativa inspirada na música **One Less Lonely Girl**, de Justin Bieber.

O projeto foi desenvolvido utilizando **HTML, CSS e JavaScript**, combinando reprodução de áudio, letra sincronizada e efeitos visuais animados.

## ✨ Funcionalidades

* 🎵 Player de música integrado
* 📝 Letra sincronizada em tempo real
* 💜 Interface com efeito Glassmorphism
* 🌟 Estrelas animadas no plano de fundo
* 🎶 Emojis musicais flutuantes
* 📱 Layout responsivo
* 🎧 Barra de progresso interativa
* ✨ Destaque automático da linha atual da música

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Audio API
* Canvas API
